# Сборка

## Один раз

```sh
brew install xcodegen
```

Впиши свой Team ID в `Config/Signing.xcconfig` (Xcode → Settings → Accounts → твой Apple ID → колонка Team ID).

## Одна команда, которая проверит всё

```sh
./tools/check.sh
```

Проверит сценарий, прогонит линтер и тесты ядра, сгенерирует проект и соберёт приложение под симулятор.
Если что-то сломалось — сложит **только ошибки** в `build-errors.txt`. Этот файл можно прислать целиком.

```sh
./tools/check.sh core           # только тесты ядра, пара секунд
./tools/check.sh app            # только сборка приложения
python3 tools/content.py        # сценарий: ссылки, тупики, баланс — без Xcode
python3 tools/lint.py           # статические проверки Swift — без Xcode
```

Код ни разу не компилировался — он писался без Mac. В первый раз ошибки почти наверняка будут:
пришли `build-errors.txt`, поправлю.

## Запуск на своём айфоне

Нужен Mac с Xcode. Собрать приложение на самом айфоне нельзя — только на Mac, а потом установить по кабелю.

1. Установи **Xcode** из App Store (большой, ~10 ГБ) и открой его один раз — он доустановит компоненты.
2. В терминале:
   ```sh
   brew install xcodegen
   git clone https://github.com/Lahmatov/sad-migrants-game.git
   cd sad-migrants-game
   ./tools/check.sh
   ```
   Если что-то упало — пришли `build-errors.txt`.
3. **Подпись.** Xcode → Settings → Accounts → «+» → войди своим Apple ID (бесплатный подходит). Скопируй Team ID и впиши в `Config/Signing.xcconfig`:
   ```
   DEVELOPMENT_TEAM = ABCDE12345
   ```
4. ```sh
   xcodegen generate
   open MigrantSad.xcodeproj
   ```
5. Подключи айфон кабелем, на телефоне нажми «Доверять этому компьютеру».
6. **Режим разработчика** на айфоне: Настройки → Конфиденциальность и безопасность → Режим разработчика → включить, телефон перезагрузится. Пункт появляется после первого подключения к Xcode.
7. В Xcode наверху выбери свой айфон вместо симулятора и нажми **⌘R**.
8. При первом запуске телефон скажет «Ненадёжный разработчик»: Настройки → Основные → VPN и управление устройством → твой Apple ID → «Доверять».

Нужен **iOS 17** или новее.

**Бесплатный аккаунт:** приложение работает 7 дней, потом снова ⌘R с подключённым телефоном. Чтобы раздать друзьям через TestFlight и не переподписывать — Apple Developer Program, $99 в год.

`MigrantSad.xcodeproj` не лежит в репозитории — он собирается из `project.yml`.
